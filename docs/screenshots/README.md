# Screenshots

Drop PNG captures here using the **exact file names** below, then in the root `README.md` change each image `src` from `.svg` to `.png`.

| File | What to capture |
|---|---|
| `inbox-dark.png` | Full window, dark theme, an ERROR selected, stack visible |
| `inbox-light.png` | Same inbox in light theme |
| `issue-stack.png` | Detail pane close-up: custom frames highlighted, Hybris frames folded |
| `business-filter.png` | A business-id chip active (order / product / cronjob / ImpEx) |
| `history.png` | History panel open, more than one session listed |

Tips:

- 1600×900 or wider reads well on GitHub.
- Crop browser chrome if you want; keep the Radar header and both panes.
- Dark shot first — that is the default theme.
